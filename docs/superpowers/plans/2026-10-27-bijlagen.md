# Bijlagen bij taken Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Foto's en PDF's aan een taak kunnen hangen (uploaden, plakken, slepen, bekijken, verwijderen), automatisch opruimen 30 dagen na Klaar, en bijlagen + back-ups op een aparte schijf kunnen bewaren.

**Architecture:**
- **Opslag:** de metadata staat in een nieuwe tabel `bijlagen`. De bestanden staan op schijf in `BIJLAGEN_MAP`, met het uuid als naam.
- **Upload en download** lopen via twee route handlers. De logica zit in `src/lib/web/bijlagen-http.ts`, zodat die zonder Next-context testbaar is. Verwijderen gaat via een server action.
- **Browser:** foto's worden vóór de upload verkleind naar JPEG, met een canvas.
- **Worker:** ruimt elke nacht op en meldt een mislukte back-up via ntfy.
- **install.sh:** vraagt eenmalig naar een map op de tweede schijf en zet daar een controlebestand neer.

**Tech Stack:** Next.js 16 (App Router, route handlers, server actions), React 19, Tailwind 4, postgres.js, Vitest (unit en integratie met Testcontainers), Playwright, bash en shellcheck.

**Spec:** `docs/superpowers/specs/2026-10-27-bijlagen-design.md`

## Global Constraints

- **Toegestane typen:** `image/jpeg`, `image/png`, `image/webp`, `application/pdf`. Het type wordt bepaald uit de eerste bytes, nooit uit de naam of de meegestuurde MIME.
- **Limieten:** max 10 MB per bestand (`10 * 1024 * 1024`), max 10 bijlagen per taak, foto's max 2000 px langste zijde, JPEG-kwaliteit 0,85.
- **Opruimen:** bijlagen van taken met `status = 'klaar'` en `klaar_op` ouder dan 30 dagen. Losse bestanden worden opgeruimd als ze ouder zijn dan 1 uur. De cron draait om 03:30 Europe/Amsterdam.
- **Controlebestand:** `.takenbord-opslag`. De omgevingsvariabelen zijn `BIJLAGEN_MAP`, `OPSLAG_CONTROLE` (`1` = aan), `BIJLAGEN_OPSLAG`, `BACKUP_OPSLAG` en `OPSLAG_MAP` (dat laatste alleen in .env, voor install.sh).
- **Foutteksten (Nederlands, exact):**
  - "Te groot (max 10 MB)."
  - "Dit bestandstype kan niet (alleen foto's en PDF's)."
  - "Maximaal 10 bijlagen per taak."
  - "Opslagschijf niet gevonden, waarschuw de beheerder."
- **Geschiedenis:** het formaat is `{ bijlage: { oud, nieuw } }`. Het automatisch opruimen schrijft geen historie.
- **Code-stijl:** Nederlandstalige namen, net als de rest van de code. Commentaar alleen waar het iets uitlegt dat niet in de code staat.
- **Next.js:** dit is Next 16 en wijkt af van oudere versies. Lees bij twijfel de gids in `node_modules/next/dist/docs/`. Er is geen `proxy.ts`, dus route handlers hebben geen limiet op de body-grootte; die limiet bewaken we zelf.

  - Integratie (Docker moet draaien): `npx vitest run --project integratie`
  - E2E: `npx playwright test`

```ts
export const BIJLAGE_TYPES = ['image/jpeg', 'image/png', 'image/webp', 'application/pdf'] as const;
export type BijlageType = (typeof BIJLAGE_TYPES)[number];
export type Bijlage = { id: string; naam: string; type: BijlageType; grootte: number };

export const MAX_BIJLAGE_BYTES = 10 * 1024 * 1024;
export const MAX_BIJLAGEN_PER_TAAK = 10;
export const BEWAAR_DAGEN_NA_KLAAR = 30;
/** Langste zijde van een foto na verkleinen; een QR-code blijft dan goed scanbaar. */
export const MAX_ZIJDE = 2000;

const ascii = (s: string) => [...s].map((c) => c.charCodeAt(0));
const begintMet = (b: Uint8Array, kop: number[], vanaf = 0) =>
  b.length >= vanaf + kop.length && kop.every((x, i) => b[vanaf + i] === x);

/** Bepaalt het type uit de eerste bytes; naam en meegestuurd type tellen niet. */
export function bepaalType(b: Uint8Array): BijlageType | null {
  if (begintMet(b, [0xff, 0xd8, 0xff])) return 'image/jpeg';
  if (begintMet(b, [0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a])) return 'image/png';
  if (begintMet(b, ascii('RIFF')) && begintMet(b, ascii('WEBP'), 8)) return 'image/webp';
  if (begintMet(b, ascii('%PDF-'))) return 'application/pdf';
  return null;
}

/** Alleen het laatste deel van een pad, zonder stuurtekens, max 200 tekens. */
export function schoonNaam(naam: string): string {
  const laatste = naam.split(/[\\/]/).pop() ?? '';
  const zonderStuur = [...laatste].filter((c) => c.charCodeAt(0) >= 32 && c.charCodeAt(0) !== 127).join('');
  return zonderStuur.trim().slice(0, 200).trim() || 'bijlage';
}

export function alsJpgNaam(naam: string): string {
  const punt = naam.lastIndexOf('.');
  return `${punt > 0 ? naam.slice(0, punt) : naam}.jpg`;
}

/** Naam voor een geplakte afbeelding zonder eigen naam. Geen ':' erin: Windows weigert die in bestandsnamen. */
export function plakNaam(nu: Date = new Date()): string {
  const delen = new Intl.DateTimeFormat('nl-NL', {
    timeZone: 'Europe/Amsterdam', day: '2-digit', month: '2-digit', hour: '2-digit', minute: '2-digit', hourCycle: 'h23',
  }).formatToParts(nu);
  const deel = (t: Intl.DateTimeFormatPartTypes) => delen.find((p) => p.type === t)?.value ?? '';
  return `Schermafbeelding ${deel('day')}-${deel('month')} ${deel('hour')}.${deel('minute')}.jpg`;
}

export function soortVerwerking(type: string): 'verklein' | 'ongewijzigd' | 'weiger' {
  if (type.startsWith('image/')) return 'verklein';
  if (type === 'application/pdf') return 'ongewijzigd';
  return 'weiger';
}

export const magOngewijzigd = (type: string): boolean => ['image/jpeg', 'image/png', 'image/webp'].includes(type);

export function formatGrootte(bytes: number): string {
  if (bytes < 1024) return `${bytes} B`;
  if (bytes < 1024 * 1024) return `${Math.round(bytes / 1024)} kB`;
  return `${(bytes / (1024 * 1024)).toFixed(1).replace('.', ',')} MB`;
}
```

- [ ] **Step 7: Write the migration** — `migrations/005_bijlagen.sql`

```sql
create table bijlagen (
  id uuid primary key default gen_random_uuid(),
  taak_id uuid not null references taken(id) on delete cascade,
  naam text not null check (char_length(naam) between 1 and 200),
  type text not null check (type in ('image/jpeg', 'image/png', 'image/webp', 'application/pdf')),
  grootte integer not null check (grootte between 1 and 10485760),
  aangemaakt_door uuid references gebruikers(id) on delete set null,
  aangemaakt_op timestamptz not null default now()
);
create index bijlagen_taak on bijlagen (taak_id, aangemaakt_op);

create or replace view taken_weergave as
select
  t.id, t.bord_id, t.titel, t.omschrijving, t.datum,
  to_char(t.tijd, 'HH24:MI') as tijd,
  t.prioriteit, t.status, t.oorspronkelijke_datum, t.uitgesteld_van, t.gemist,
  t.herhaling_id, t.afwijkend, t.versie, t.aangemaakt_op, t.gewijzigd_op, t.klaar_op,
  ag.naam as aangemaakt_door_naam,
  gg.naam as gewijzigd_door_naam,
  h.type as herhaling_type,
  h.weekdagen as herhaling_weekdagen,
  h.interval_weken as herhaling_interval,
  bo.naam as bord_naam,
  bo.gearchiveerd as bord_gearchiveerd,
  coalesce((
    select json_agg(json_build_object(
      'naam', s.naam, 'adres', s.adres, 'lat', s.lat, 'lng', s.lng,
      'googlePlaceId', s.google_place_id, 'locatieId', s.locatie_id) order by s.volgorde)
    from taak_stops s where s.taak_id = t.id
  ), '[]'::json) as stops,
  coalesce((
    select json_agg(json_build_object('id', b.id, 'naam', b.naam, 'type', b.type, 'grootte', b.grootte)
      order by b.aangemaakt_op, b.id)
    from bijlagen b where b.taak_id = t.id
  ), '[]'::json) as bijlagen
from taken t
join borden bo on bo.id = t.bord_id
left join gebruikers ag on ag.id = t.aangemaakt_door
left join gebruikers gg on gg.id = t.gewijzigd_door
left join herhalingen h on h.id = t.herhaling_id;
```

`create or replace view` mag alleen kolommen achteraan toevoegen. De eerste kolommen zijn daarom gelijk aan die in `002_locaties.sql`.

import path from 'node:path';
import { OpslagOntbreekt } from './fouten';

/** Staat in een map op de opslagschijf; ontbreekt het, dan is de schijf (nog) niet aangekoppeld. */
export const OPSLAG_MARKER = '.takenbord-opslag';

/** Aan bij een aparte opslagschijf: dan moet het controlebestand er zijn en maken we nooit zelf mappen aan. */
export const opslagControleAan = (): boolean => process.env.OPSLAG_CONTROLE === '1';

export const bijlagenMap = (): string => path.resolve(process.env.BIJLAGEN_MAP || '.opslag/bijlagen');

export async function opslagAanwezig(map: string, controle = opslagControleAan()): Promise<boolean> {
  if (!controle) return true;
  try {
    await access(path.join(map, OPSLAG_MARKER));
    return true;
  } catch {
    return false;
  }
}

export async function vereisOpslag(map: string, controle = opslagControleAan()): Promise<void> {
  if (controle) {
    if (!(await opslagAanwezig(map, true))) throw new OpslagOntbreekt();
    return;
  }
  await mkdir(map, { recursive: true });
}

const TAAK_NIET_GEVONDEN = 'Taak niet gevonden';

async function logBijlage(tx: Tx, taakId: string, gebruikerId: string, oud: string | null, nieuw: string | null): Promise<void> {
  const w = JSON.stringify({ bijlage: { oud, nieuw } });

/** Schrijft eerst het bestand (via .deel) en legt dan de rij vast; mislukt dat, dan gaat het bestand weer weg. */
export async function voegBijlageToe(ctx: Context, taakId: string, invoer: { naam: string; inhoud: Uint8Array }): Promise<Bijlage> {
  if (!isUuid(taakId)) throw new NietGevonden(TAAK_NIET_GEVONDEN);
  if (invoer.inhoud.length === 0) throw new Ongeldig('Het bestand is leeg.');
  if (invoer.inhoud.length > MAX_BIJLAGE_BYTES) throw new TeGroot('Te groot (max 10 MB).');
  const type = bepaalType(invoer.inhoud);
  if (!type) throw new Ongeldig("Dit bestandstype kan niet (alleen foto's en PDF's).");
  const naam = schoonNaam(invoer.naam);
  const map = bijlagenMap();
  await vereisOpslag(map);

  const id = randomUUID();
  const doel = path.join(map, id);
  try {
    await writeFile(`${doel}.deel`, invoer.inhoud);
    await rename(`${doel}.deel`, doel);
  } catch (e) {
    await rm(`${doel}.deel`, { force: true });
    throw e;
  }
  try {
    await transactie(async (tx) => {
      const [t] = await tx<{ bordId: string }[]>`select bord_id from taken where id = ${taakId} for update`;
      if (!t) throw new NietGevonden(TAAK_NIET_GEVONDEN);
      const [{ aantal }] = await tx<{ aantal: number }[]>`select count(*)::int as aantal from bijlagen where taak_id = ${taakId}`;
      if (aantal >= MAX_BIJLAGEN_PER_TAAK) throw new TeVeelBijlagen(`Maximaal ${MAX_BIJLAGEN_PER_TAAK} bijlagen per taak.`);
      await tx`
        insert into bijlagen (id, taak_id, naam, type, grootte, aangemaakt_door)
        values (${id}, ${taakId}, ${naam}, ${type}, ${invoer.inhoud.length}, ${ctx.gebruikerId})`;
      await logBijlage(tx, taakId, ctx.gebruikerId, null, naam);
      await meldWijziging(tx, t.bordId);
    });
  } catch (e) {
    await rm(doel, { force: true });
    throw e;
  }
  return { id, naam, type, grootte: invoer.inhoud.length };
}

export async function verwijderBijlage(ctx: Context, id: string): Promise<void> {
  if (!isUuid(id)) throw new NietGevonden(BIJLAGE_NIET_GEVONDEN);
  await transactie(async (tx) => {
    const [b] = await tx<{ taakId: string; naam: string; bordId: string }[]>`
      delete from bijlagen b using taken t
      where b.id = ${id} and t.id = b.taak_id
      returning b.taak_id, b.naam, t.bord_id`;
    if (!b) throw new NietGevonden(BIJLAGE_NIET_GEVONDEN);
    await logBijlage(tx, b.taakId, ctx.gebruikerId, b.naam, null);
    await meldWijziging(tx, b.bordId);
  });
  // Lukt dit niet, dan ruimt de nachtrun het losse bestand op.
  await rm(path.join(bijlagenMap(), id), { force: true }).catch(() => {});
}

export async function haalBijlage(id: string): Promise<{ naam: string; type: BijlageType; pad: string }> {
  if (!isUuid(id)) throw new NietGevonden(BIJLAGE_NIET_GEVONDEN);
  const [b] = await db()<{ naam: string; type: BijlageType }[]>`select naam, type from bijlagen where id = ${id}`;
  if (!b) throw new NietGevonden(BIJLAGE_NIET_GEVONDEN);
  return { naam: b.naam, type: b.type, pad: path.join(bijlagenMap(), id) };
}

import { Readable } from 'node:stream';
import type { SessieGebruiker } from '../auth/sessies';
import { haalBijlage, voegBijlageToe } from '../diensten/bijlagen';
import { MAX_BIJLAGE_BYTES } from '../domein/bijlagen';
import { Fout, NietGevonden, OpslagOntbreekt, TeGroot, TeVeelBijlagen } from '../fouten';

/** Ruimte voor de multipart-omhulling rond het bestand. */
const MARGE = 64 * 1024;

const fout = (status: number, tekst: string) => Response.json({ fout: tekst }, { status });

function statusVoor(e: Fout): number {
  if (e instanceof NietGevonden) return 404;
  if (e instanceof TeVeelBijlagen) return 409;
  if (e instanceof TeGroot) return 413;
  if (e instanceof OpslagOntbreekt) return 503;
  return 400;
}

/** Route handlers hebben geen ingebouwde CSRF-check zoals server actions; daarom de Origin zelf vergelijken. */
export function zelfdeHerkomst(verzoek: Request, appUrl: string | undefined): boolean {
  const origin = verzoek.headers.get('origin');
  if (!origin || !appUrl) return false;
  try {
    return new URL(origin).origin === new URL(appUrl).origin;
  } catch {
    return false;
  }
}

export async function verwerkUpload(
  verzoek: Request, gebruiker: SessieGebruiker | null, taakId: string, appUrl = process.env.APP_URL,
): Promise<Response> {
  if (!gebruiker) return fout(401, 'Niet ingelogd');
  if (!zelfdeHerkomst(verzoek, appUrl)) return fout(403, 'Verzoek geweigerd');
  // Vóór het inlezen afkappen, zodat een enorm verzoek niet in het geheugen belandt.
  if (Number(verzoek.headers.get('content-length') ?? 0) > MAX_BIJLAGE_BYTES + MARGE) return fout(413, 'Te groot (max 10 MB).');
  let bestand: FormDataEntryValue | null;
  try {
    bestand = (await verzoek.formData()).get('bestand');
  } catch {
    return fout(400, 'Ongeldig verzoek');
  }
  if (!(bestand instanceof File)) return fout(400, 'Geen bestand meegestuurd');
  try {
    const inhoud = new Uint8Array(await bestand.arrayBuffer());
    const b = await voegBijlageToe({ gebruikerId: gebruiker.id, rol: gebruiker.rol }, taakId, { naam: bestand.name, inhoud });
    return Response.json(b, { status: 201 });
  } catch (e) {
    if (e instanceof Fout) return fout(statusVoor(e), e.message);
    const code = crypto.randomUUID().slice(0, 8);
    console.error(`[fout ${code}]`, e);
    return fout(500, `Er ging iets mis (foutcode ${code}). Probeer het opnieuw.`);
  }
}

export async function verwerkDownload(gebruiker: SessieGebruiker | null, id: string): Promise<Response> {
  if (!gebruiker) return fout(401, 'Niet ingelogd');
  let b: Awaited<ReturnType<typeof haalBijlage>>;
  try {
    b = await haalBijlage(id);
  } catch (e) {
    if (e instanceof NietGevonden) return fout(404, e.message);
    throw e;
  }
  let grootte: number;
  try {
    grootte = (await stat(b.pad)).size;
  } catch {
    return fout(404, 'Bestand niet gevonden');
  }
  return new Response(Readable.toWeb(createReadStream(b.pad)) as ReadableStream<Uint8Array>, {
    headers: {
      'Content-Type': b.type,
      'Content-Length': String(grootte),
      'Content-Disposition': `inline; filename*=UTF-8''${encodeURIComponent(b.naam)}`,
      'X-Content-Type-Options': 'nosniff',
      'Cache-Control': 'private, max-age=3600',
    },
  });
}

```ts
import { readdir, rm, stat } from 'node:fs/promises';
import path from 'node:path';
import { db, transactie } from '../../lib/db/client';
import { meldWijziging } from '../../lib/db/gebeurtenissen';
import { BEWAAR_DAGEN_NA_KLAAR } from '../../lib/domein/bijlagen';
import { opslagAanwezig } from '../../lib/opslag';

const BIJLAGE_BESTAND = /^([0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12})(\.deel)?$/;
/** Jonger dan dit kan een upload zijn die nog bezig is. */
const LOS_NA_MS = 60 * 60 * 1000;

/**
 * Verwijdert bijlagen van taken die langer dan 30 dagen klaar zijn, en daarna bestanden zonder rij
 * (van verwijderde taken of afgebroken uploads). Andere bestanden in de map blijven staan.
 */
export async function ruimBijlagenOp(o: { map: string; nu?: Date; controle?: boolean }): Promise<{ oud: number; los: number }> {
  const nu = o.nu ?? new Date();
  const grens = new Date(nu.getTime() - BEWAAR_DAGEN_NA_KLAAR * 24 * 60 * 60 * 1000);
  const oud = await transactie(async (tx) => {
    const rijen = await tx<{ id: string; bordId: string }[]>`
      delete from bijlagen b using taken t
      where t.id = b.taak_id and t.status = 'klaar' and t.klaar_op < ${grens}
      returning b.id, t.bord_id`;
    for (const bordId of new Set(rijen.map((r) => r.bordId))) await meldWijziging(tx, bordId);
    return rijen.length;
  });

  if (!(await opslagAanwezig(o.map, o.controle))) return { oud, los: 0 };
  let namen: string[];
  try {
    namen = await readdir(o.map);
  } catch {
    return { oud, los: 0 };
  }
  const kandidaten = namen.flatMap((naam) => {
    const m = BIJLAGE_BESTAND.exec(naam);
    return m ? [{ naam, id: m[1], deel: Boolean(m[2]) }] : [];
  });
  const ids = [...new Set(kandidaten.map((k) => k.id))];
  const bekend = new Set(
    ids.length ? (await db()<{ id: string }[]>`select id from bijlagen where id in ${db()(ids)}`).map((r) => r.id) : [],
  );
  let los = 0;
  for (const k of kandidaten) {
    if (bekend.has(k.id) && !k.deel) continue;
    const pad = path.join(o.map, k.naam);
    const s = await stat(pad).catch(() => null);
    if (!s || nu.getTime() - s.mtimeMs < LOS_NA_MS) continue;
    await rm(pad, { force: true });
    los++;
  }
  return { oud, los };
}

import {
  alsJpgNaam, type Bijlage, magOngewijzigd, MAX_BIJLAGE_BYTES, MAX_ZIJDE, plakNaam, soortVerwerking,
} from '../domein/bijlagen';

const TE_GROOT = 'Te groot (max 10 MB).';

async function verkleinNaarJpg(f: Blob): Promise<Blob> {
  const beeld = await createImageBitmap(f);
  const schaal = Math.min(1, MAX_ZIJDE / Math.max(beeld.width, beeld.height));
  const breedte = Math.max(1, Math.round(beeld.width * schaal));
  const hoogte = Math.max(1, Math.round(beeld.height * schaal));
  const canvas = document.createElement('canvas');
  canvas.width = breedte;
  canvas.height = hoogte;
  const c = canvas.getContext('2d');
  if (!c) throw new Error('Geen canvas');
  c.fillStyle = '#fff'; // transparante PNG's krijgen een witte achtergrond, zodat een QR-code leesbaar blijft
  c.fillRect(0, 0, breedte, hoogte);
  c.drawImage(beeld, 0, 0, breedte, hoogte);
  beeld.close();
  return new Promise((klaar, faal) => canvas.toBlob((b) => (b ? klaar(b) : faal(new Error('toBlob mislukt'))), 'image/jpeg', 0.85));
}

/** Maakt een gekozen of geplakt bestand klaar voor upload: foto's verkleind naar JPEG (zonder EXIF), PDF's ongewijzigd. */
export async function bereidVoor(f: File, nu: Date = new Date()): Promise<{ bestand: Blob; naam: string } | { fout: string }> {
  const naam = f.name && f.name !== 'image.png' ? f.name : plakNaam(nu);
  const soort = soortVerwerking(f.type);
  if (soort === 'weiger') return { fout: "Dit bestandstype kan niet (alleen foto's en PDF's)." };
  if (soort === 'ongewijzigd') return f.size > MAX_BIJLAGE_BYTES ? { fout: TE_GROOT } : { bestand: f, naam };
  try {
    const jpg = await verkleinNaarJpg(f);
    return jpg.size > MAX_BIJLAGE_BYTES ? { fout: TE_GROOT } : { bestand: jpg, naam: alsJpgNaam(naam) };
  } catch {
    if (!magOngewijzigd(f.type)) return { fout: 'Dit fototype kan niet.' };
    return f.size > MAX_BIJLAGE_BYTES ? { fout: TE_GROOT } : { bestand: f, naam };
  }
}

export type UploadResultaat = { ok: true; bijlage: Bijlage } | { ok: false; fout: string };

/** XHR in plaats van fetch: alleen zo is de voortgang van een upload te volgen. */
export function uploadBijlage(taakId: string, bestand: Blob, naam: string, opVoortgang: (fractie: number) => void): Promise<UploadResultaat> {
  return new Promise((klaar) => {
    const fd = new FormData();
    fd.append('bestand', bestand, naam);
    const xhr = new XMLHttpRequest();
    xhr.open('POST', `/api/taken/${encodeURIComponent(taakId)}/bijlagen`);
    xhr.upload.onprogress = (e) => { if (e.lengthComputable) opVoortgang(e.loaded / e.total); };
    xhr.onload = () => {
      let data: unknown = null;
      try { data = JSON.parse(xhr.responseText); } catch { /* geen JSON */ }
      if (xhr.status === 201) klaar({ ok: true, bijlage: data as Bijlage });
      else klaar({ ok: false, fout: (data as { fout?: string } | null)?.fout ?? `Uploaden mislukt (${xhr.status}).` });
    };
    xhr.onerror = () => klaar({ ok: false, fout: 'Geen verbinding. Probeer het opnieuw.' });
    xhr.send(fd);
  });
}

'use client';

import { useRouter } from 'next/navigation';
import { type Ref, useEffect, useImperativeHandle, useRef, useState } from 'react';
import { verwijderBijlageActie } from '@/app/(app)/bord/acties';
import { BestandIcoon, KruisIcoon, PaperclipIcoon } from '@/components/iconen';
import { Melding } from '@/components/ui';
import { type Bijlage, formatGrootte, MAX_BIJLAGEN_PER_TAAK } from '@/lib/domein/bijlagen';
import { bereidVoor, uploadBijlage } from '@/lib/web/bijlage-upload';

type Lokaal = {
  soort: 'lokaal';
  sleutel: number;
  naam: string;
  bestand: Blob | null;
  status: 'wacht' | 'bezig' | 'fout';
  voortgang: number;
  fout: string | null;
};
type Item = { soort: 'opgeslagen'; bijlage: Bijlage } | Lokaal;

export type BijlagenHandvat = {
  /** Bereidt bestanden voor; bij een bestaande taak worden ze meteen geüpload. */
  voegToe: (bestanden: File[]) => void;
  /** Uploadt alles wat nog wacht naar de (net aangemaakte) taak; false als iets mislukte. */
  uploadAlles: (taakId: string) => Promise<boolean>;
};

export function BijlagenBlok({ taakId, begin, handvat }: { taakId: string | null; begin: Bijlage[]; handvat?: Ref<BijlagenHandvat | null> }) {
  const router = useRouter();
  const [items, setItems] = useState<Item[]>(() => begin.map((bijlage) => ({ soort: 'opgeslagen', bijlage })));
  const [fout, setFout] = useState<string | null>(null);
  // Async code leest de lijst via deze ref; hij wordt tegelijk met de state bijgewerkt.
  const itemsRef = useRef(items);
  const taakIdRef = useRef(taakId);
  const voorbereiding = useRef<Promise<void>>(Promise.resolve());
  const teller = useRef(0);
  useEffect(() => { taakIdRef.current = taakId; }, [taakId]);

  function zet(wijzig: (lijst: Item[]) => Item[]) {
    itemsRef.current = wijzig(itemsRef.current);
    setItems(itemsRef.current);
  }
  const werkBij = (sleutel: number, w: Partial<Lokaal>) =>
    zet((l) => l.map((i) => (i.soort === 'lokaal' && i.sleutel === sleutel ? { ...i, ...w } : i)));

  async function upload(item: Lokaal, naarTaak: string): Promise<boolean> {
    if (!item.bestand) return true; // al afgekeurd en gemeld; telt niet als mislukte upload
    werkBij(item.sleutel, { status: 'bezig', voortgang: 0, fout: null });
    const r = await uploadBijlage(naarTaak, item.bestand, item.naam, (v) => werkBij(item.sleutel, { voortgang: v }));
    if (!r.ok) {
      werkBij(item.sleutel, { status: 'fout', fout: r.fout });
      return false;
    }
    zet((l) => l.map((i) => (i.soort === 'lokaal' && i.sleutel === item.sleutel ? { soort: 'opgeslagen', bijlage: r.bijlage } : i)));
    router.refresh();
    return true;
  }

  function voegToe(bestanden: File[]) {
    voorbereiding.current = voorbereiding.current.then(async () => {
      for (const f of bestanden) {
        const bezet = itemsRef.current.filter((i) => i.soort === 'opgeslagen' || i.bestand !== null).length;
        const v = bezet >= MAX_BIJLAGEN_PER_TAAK ? { fout: `Maximaal ${MAX_BIJLAGEN_PER_TAAK} bijlagen per taak.` } : await bereidVoor(f);
        const item: Lokaal = 'fout' in v
          ? { soort: 'lokaal', sleutel: ++teller.current, naam: f.name || 'bijlage', bestand: null, status: 'fout', voortgang: 0, fout: v.fout }
          : { soort: 'lokaal', sleutel: ++teller.current, naam: v.naam, bestand: v.bestand, status: 'wacht', voortgang: 0, fout: null };
        zet((l) => [...l, item]);
        if (taakIdRef.current && item.bestand) await upload(item, taakIdRef.current);
      }
    });
  }

  async function uploadAlles(id: string): Promise<boolean> {
    taakIdRef.current = id;
    await voorbereiding.current;
    let alles = true;
    for (const i of itemsRef.current) {
      if (i.soort === 'lokaal' && i.status !== 'bezig' && !(await upload(i, id))) alles = false;
    }
    return alles;
  }

  useImperativeHandle(handvat, () => ({ voegToe, uploadAlles }));

  async function verwijder(b: Bijlage) {
    if (!confirm('Bijlage verwijderen?')) return;
    const r = await verwijderBijlageActie(b.id);
    if (!r.ok) return setFout(r.fout);
    setFout(null);
    zet((l) => l.filter((i) => !(i.soort === 'opgeslagen' && i.bijlage.id === b.id)));
    router.refresh();
  }

  return (
    <div>
      <span className="mb-1.5 block text-xs font-medium text-tekst-zacht">Bijlagen</span>
      {items.length > 0 && (
        <ul className="mb-2 grid grid-cols-3 gap-2" aria-label="Bijlagen">
          {items.map((i) =>
            i.soort === 'opgeslagen' ? (
              <li key={i.bijlage.id} className="relative">
                <a
                  href={`/api/bijlagen/${i.bijlage.id}`}
                  target="_blank"
                  rel="noopener"
                  aria-label={i.bijlage.naam}
                  title={i.bijlage.naam}
                  className="block aspect-square overflow-hidden rounded-lg border border-rand bg-achtergrond"
                >
                  {i.bijlage.type === 'application/pdf' ? (
                    <span className="flex size-full flex-col items-center justify-center gap-1 p-1.5 text-center text-[11px] text-tekst-zacht">
                      <BestandIcoon />
                      <span className="line-clamp-2 break-all">{i.bijlage.naam}</span>
                      <span>{formatGrootte(i.bijlage.grootte)}</span>
                    </span>
                  ) : (
                    <img src={`/api/bijlagen/${i.bijlage.id}`} alt="" loading="lazy" className="size-full object-cover" />
                  )}
                </a>
                <button
                  type="button"
                  aria-label={`${i.bijlage.naam} verwijderen`}
                  onClick={() => void verwijder(i.bijlage)}
                  className="absolute top-1 right-1 rounded-full bg-black/60 p-1 text-white hover:bg-black/80"
                >
                  <KruisIcoon />
                </button>
              </li>
            ) : (
              <li key={i.sleutel} className="relative flex aspect-square flex-col justify-between rounded-lg border border-rand bg-achtergrond p-1.5 text-[11px]">
                <span className="line-clamp-2 break-all text-tekst-zacht">{i.naam}</span>
                {i.status === 'fout' ? (
                  <span role="alert" className="text-prio-nu">{i.fout}</span>
                ) : (
                  <span className="h-1.5 overflow-hidden rounded-full bg-rand" aria-label={`${i.naam} wordt geüpload`}>
                    <span className="block h-full bg-accent transition-[width]" style={{ width: `${Math.round(i.voortgang * 100)}%` }} />
                  </span>
                )}
                {i.status === 'fout' && (
                  <button
                    type="button"
                    aria-label={`${i.naam} weghalen`}
                    onClick={() => zet((l) => l.filter((x) => !(x.soort === 'lokaal' && x.sleutel === i.sleutel)))}
                    className="absolute top-1 right-1 rounded-full bg-black/60 p-1 text-white"
                  >
                    <KruisIcoon />
                  </button>
                )}
              </li>
            ),
          )}
        </ul>
      )}
      <label className="inline-flex h-9 cursor-pointer items-center gap-1.5 rounded-lg border border-rand px-3 text-sm text-tekst-zacht hover:bg-kaart">
        <PaperclipIcoon />
        Foto of bestand toevoegen
        <input
          type="file"
          accept="image/*,application/pdf"
          multiple
          className="sr-only"
          onChange={(e) => {
            voegToe([...(e.target.files ?? [])]);
            e.target.value = '';
          }}
        />
      </label>
      <p className="mt-1 hidden text-xs text-tekst-flauw sm:block">Of plak een screenshot met Ctrl+V, of sleep een bestand in dit venster.</p>
      {fout && <div className="mt-2"><Melding>{fout}</Melding></div>}
    </div>
  );
}

env_heeft_sleutel() { # $1 = bestand, $2 = sleutel; ook waar bij een lege waarde
  [[ -f "$1" ]] && grep -q "^$2=" "$1"
}

opslag_pad_probleem() { # $1 = pad; leeg als het bruikbaar is
  if [[ "$1" != /* || "$1" == / ]]; then
    echo "Gebruik een volledig pad dat met / begint, bijv. /mnt/opslag/takenbord."
  elif [[ ! "$1" =~ ^/[A-Za-z0-9._/-]+$ ]]; then
    echo "Gebruik alleen letters, cijfers en . _ - / in het pad."
  elif [[ ! -d "$(dirname "$1")" ]]; then
    echo "De map $(dirname "$1") bestaat niet. Is de schijf aangekoppeld?"
  fi
}

op_systeemschijf() { # $1 = bestaande map; waar als die op hetzelfde bestandssysteem staat als /
  [[ "$(df --output=source "$1" | tail -1)" == "$(df --output=source / | tail -1)" ]]
}
```

Zet bij de stappen, na `schrijf_env`:

```bash
verhuis_backups() { # $1 = nieuwe back-upmap; kopieert eenmalig uit het oude volume, overschrijft niets
  "${DOCKER[@]}" volume inspect takenbord_backups >/dev/null 2>&1 || return 0
  info "Bestaande back-ups overzetten…"
  # shellcheck disable=SC2016 # $f wordt in de container uitgewerkt
  "${DOCKER[@]}" run --rm --user 1000:1000 --entrypoint sh -v takenbord_backups:/oud:ro -v "$1":/nieuw takenbord-worker \
    -c 'for f in /oud/*.dump; do [ -e "$f" ] || continue; [ -e "/nieuw/${f##*/}" ] || cp "$f" /nieuw/; done'
  gelukt "Back-ups overgezet (het oude volume takenbord_backups blijft bestaan; zie README)"
}

controleer_opslag() {
  local env="$MAP/.env" map
  [[ "$(lees_env_waarde "$env" OPSLAG_CONTROLE)" == 1 ]] || return 0
  for map in "$(lees_env_waarde "$env" BIJLAGEN_OPSLAG)" "$(lees_env_waarde "$env" BACKUP_OPSLAG)"; do
    [[ -f "$map/$OPSLAG_MARKER" ]] ||
      stop_met_fout "Het controlebestand $map/$OPSLAG_MARKER ontbreekt. Is de opslagschijf aangekoppeld? Controleer met: df -h $map"
  done
}

stel_opslag_in() {
  local env="$MAP/.env" pad="" probleem antwoord
  if env_heeft_sleutel "$env" OPSLAG_MAP; then
    controleer_opslag
    return
  fi
  stap "Opslag voor bijlagen en back-ups"
  info "Heeft de server een tweede schijf? Bewaar bijlagen en back-ups daar, dan ben je niet alles kwijt als één schijf kapotgaat."
  while true; do
    vraag pad "Map voor bijlagen en back-ups (bijv. /mnt/opslag/takenbord; Enter = systeemschijf)"
    pad="${pad%/}"
    [[ -z "$pad" ]] && break
    probleem="$(opslag_pad_probleem "$pad")"
    if [[ -n "$probleem" ]]; then
      waarschuw "$probleem"
      continue
    fi
    if op_systeemschijf "$(dirname "$pad")"; then
      vraag antwoord "Die map staat op de systeemschijf. Toch gebruiken? (j/n)"
      [[ "${antwoord,,}" == j* ]] || continue
    fi
    break
  done
  if [[ -z "$pad" ]]; then
    zet_env_waarde "$env" OPSLAG_MAP ""
    gelukt "Bijlagen en back-ups blijven op de systeemschijf"
    return
  fi
  "${SUDO[@]}" mkdir -p "$pad/bijlagen" "$pad/backups"
  "${SUDO[@]}" touch "$pad/bijlagen/$OPSLAG_MARKER" "$pad/backups/$OPSLAG_MARKER"
  "${SUDO[@]}" chown -R 1000:1000 "$pad/bijlagen" "$pad/backups"
  verhuis_backups "$pad/backups"
  zet_env_waarde "$env" BIJLAGEN_OPSLAG "$pad/bijlagen"
  zet_env_waarde "$env" BACKUP_OPSLAG "$pad/backups"
  zet_env_waarde "$env" OPSLAG_CONTROLE 1
  zet_env_waarde "$env" OPSLAG_MAP "$pad" # als laatste: pas dan is deze stap af
  gelukt "Bijlagen en back-ups komen in $pad"
}
```

Let op het `local pad=""`: `vraag` vult via `printf -v` de lokale variabele van de aanroeper, net als bij `vraag_instellingen`.
